# СРК · СЛР — конспект и тесты

Статический сайт (HTML/CSS/JS без сборки): теория по специализированному реанимационному комплексу и СЛР у детей,
подборка видео YouTube, интерактивные чек-листы и тест (включая распознавание ЭКГ-ритмов по фото).

Учебный материал по методичке практических занятий №3 и №4. Не заменяет клинические рекомендации.

Запуск локально: `python -m http.server` и открыть http://localhost:8000
